# Security

Kinemica Verify handles paths, manifests, and policy-like verification inputs. Security issues may therefore affect systems that consume verification results.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting or Security Advisory mechanism for this repository. Include:

- affected version or commit
- reproduction steps
- expected and observed behavior
- likely impact
- any suggested mitigation

We will acknowledge valid reports and coordinate disclosure after a fix is available.

## Security boundary

A successful verification means the supplied evidence satisfies the configured Work Contract under the verifier's rules. It does not establish that unobserved physical events occurred, certify a robot or work process as safe, or replace independent operational safeguards.
